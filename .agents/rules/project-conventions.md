# Project Rules Index

Lee `AGENTS.md` antes de trabajar y consulta las reglas relevantes para el cambio:

- [Architecture](architecture.md): límites de responsabilidades y fuentes de datos.
- [Naming and API contracts](naming.md): nombres y compatibilidad entre backend y frontend.
- [Testing](testing.md): cobertura y comandos de verificación.
- [Documentation](documentation.md): README y documentación de comportamiento.
- [Developer experience](dx.md): instalación, Compose y configuración local.
- [Security](security.md): CORS, depurador y secretos.
- [Financial data](finance.md): precisión monetaria y formato de importes.

Son reglas propuestas a partir del estado actual del repositorio. Cada regla incluye evidencia concreta para que pueda revisarse junto con el código.

Las etiquetas **Aplicación sugerida** son orientación para quien seleccione las reglas; no son metadatos ejecutables. El formato documentado por `AGENTS.md` solo especifica archivos Markdown en `.agents/rules` y no define campos como `Always`, `Auto Attached` o `Agent Requested`.
